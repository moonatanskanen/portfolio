KareliaGolfApp

Project in GitHub

KareliaGolfApp was the biggest project during my studies. We had a group of 7, where we had a Product Owner, Scrum master and five developers. The project lasted 8 weeks and I worked as a developer the first four weeks and as a Product Owner the last four.

The main idea of the application was to create a solution for golf course maintenance to keep track of their work and equipment. Our local golf club kept all of their information in Excel files and they needed a better solution for storing the information. Our application is designed to combine all of the Excel files into one place so the information is easier to edit, add and manage. Our project was graded 5/5.

This project was done using the Scrum model. It was my first time trying the Scrum model in a project. It was very educational and I learned a lot especially about Product Owner's role. I learned how to design, organize and make decisions about the product and the process. My social skills came in handy when contacting the client, chairing the meetings and instructing our team. As a developer I took part in the early stages of development. I built grids and base structures of the application as well as methods and classes that would be used later in the process.


Mörkkis HousingApp

Project in GitHub

Mörkkis project was our first big project during the first year of studies. I was a developer in this project with 4 other students. Mörkkis was made for a software production course where the main focus was to build an application using waterfall model. Our project was graded 5/5.

I was in charge of creating invoice window. It collects all the invoices made and it has the ability to filter invoices by a certain time frame. I was also partially in charge of front end, especially menu items and window borders. Pictures and logos were made by another student.

This project was my first step to building an application with an actual purpose. Mörkkis is an application for booking cabins, storing client information and invoices. This project taught me how to develop software as part of a team and how to use Git and Azure DevOps. I also learned and understood a lot about XAML, C# and SQL.


MoominsApi

Project in GitHub

This project was created as an exam assignment during my first API course. The goal was to build a simple REST API with a Moomin themed application as the subject. The API allows users to retrieve, add and delete Moomin characters. Moomins can be searched by name, or specific Moomin can be found using its number. The API also handles different HTTP status codes depending on the result of the request. The project also includes a simple console client that communicates with the API using HttpClient and JSON.

During this assignment and the course, I learned the basics of building and using REST APIs. For example, I gained experience with creating API controllers, using different requests, handling HTTP status codes and using HttpClient to communicate with an API. My course grade was 4/5.
